# Лабораторные работы по операционным системам
## Мацкевич Марк, 11 группа
Данный репозиторий содержит лабораторные работы по дисциплине "Операционные системы". Каждая лабораторная работа направлена на изучение ключевых аспектов операционных систем: создание процессов, потоков, синхронизация, межпроцессное взаимодействие.

---

## Содержание

| № | Название лабораторной работы                        | Краткое описание                                  |
|---|----------------------------------------------------|--------------------------------------------------|
| 1 | Создание процессов                                 | Создание и управление процессами, работа с файлами |
| 2 | Создание потоков                                   | Создание потоков, вычисление минимальных, максимальных значений и среднего |
| 3 | Синхронизация потоков и обработка тупиков         | Синхронизация потоков с помощью критических секций и событий, управление состояниями |
| 4 | Синхронизация процессов через общий бинарный файл | Обмен сообщениями между процессами через файл с реализацией FIFO очереди |
| 5 | Обмен данными по именованным каналам              | Клиент-серверное взаимодействие через именованные каналы, управление доступом к файлу |

---

## Организация репозитория

Каждая лабораторная работа расположена в отдельной папке с собственным `README.md`, исходными кодами и Makefile для компиляции. Рекомендуется изучать и запускать работы по порядку.

---

## Требования

- ОС: Windows (использование WinAPI для управления процессами и потоками)  
- Компилятор: GCC/MinGW или Visual Studio  
- Навыки работы с консолью и базовые знания C/C++
