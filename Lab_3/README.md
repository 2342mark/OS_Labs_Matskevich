# Лабораторная работа №3: Синхронизация потоков и обработка тупиков

## Цель

Освоить методы синхронизации потоков с помощью критических секций и событий, а также обработку тупиковых ситуаций (deadlock).

## Задача

Создать программу с главным потоком main и несколькими потоками marker, взаимодействующими через сигналы и общую память.

## Описание работы

| Поток | Функции                                                                                  |
|-------|------------------------------------------------------------------------------------------|
| main  | - Запрос размера массива и инициализация нулями                                         |
|       | - Запрос количества потоков marker                                                      |
|       | - Запуск потоков marker с передачей порядкового номера                                  |
|       | - Сигнал запуска потокам marker                                                        |
|       | - В цикле:                                                                             |
|       |    • Ожидание сигналов от marker о невозможности продолжения                           |
|       |    • Вывод массива на консоль                                                          |
|       |    • Запрос номера потока marker для завершения                                        |
|       |    • Посылка сигнала завершения и ожидание завершения потока                           |
|       |    • Вывод обновленного массива                                                        |
|       |    • Продолжение работы оставшихся потоков                                            |
|       | - Завершение после окончания всех marker                                               |
| marker| - Ожидание сигнала запуска                                                             |
|       | - Инициализация генератора случайных чисел                                            |
|       | - Циклическая генерация случайных чисел и вычисление индекса массива                   |
|       | - Если элемент массива по индексу равен нулю:                                          |
|       |    • Пометка элемента своим номером с задержками                                      |
|       | - Иначе:                                                                               |
|       |    • Вывод информации о состоянии                                                     |
|       |    • Посылка сигнала main о невозможности продолжения                                 |
|       |    • Ожидание сигнала продолжения или завершения                                      |
|       | - При сигнале завершения:                                                              |
|       |    • Очистка помеченных элементов                                                    |
|       |    • Завершение работы                                                                |

## Особенности реализации

- Применение критических секций и событий для синхронизации потоков.  
- Обработка тупиков через взаимодействие потоков и сигналы.  
- Использование общей памяти для обмена данными.  

## Инструкция по запуску

- Запустите программу.  
- Введите размер массива.  
- Введите количество потоков marker.  
- Следуйте подсказкам консоли для управления потоками.
