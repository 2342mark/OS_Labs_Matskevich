
# Лабораторная работа №1: Создание процессов

---

## Цель

Изучить создание и управление процессами в операционной системе. Освоить передачу параметров командной строки и работу с бинарными и текстовыми файлами.

---

## Задача

Разработать три консольные программы:

1. **Creator** — создает бинарный файл с записями сотрудников.  
2. **Reporter** — формирует текстовый отчет с вычислением зарплаты на основе бинарного файла.  
3. **Main** — управляющая программа, запускающая Creator и Reporter, осуществляющая ввод и вывод данных.

---

## Структура данных

```c
struct employee {
    int num;          // Идентификационный номер сотрудника
    char name[10];    // Имя сотрудника
    double hours;     // Количество отработанных часов
};
```
