# Лабораторная работа №4: Синхронизация процессов через общий бинарный файл

## Цель

Изучение межпроцессного взаимодействия и синхронизации с использованием общего бинарного файла.

## Задача

Реализовать два типа процессов:

| Процесс  | Описание                                                        |
|----------|-----------------------------------------------------------------|
| Receiver | Принимает сообщения от процессов Sender                         |
| Sender   | Отправляет сообщения процессу Receiver                          |

## Описание работы

**Receiver:**

- Запрашивает имя бинарного файла и количество записей.  
- Создаёт бинарный файл для хранения сообщений фиксированной длины.  
- Запрашивает количество процессов Sender.  
- Запускает процессы Sender, передавая имя файла.  
- Ожидает сигналов готовности от всех Sender.  
- В цикле по команде с консоли читает сообщения из файла или завершает работу.  
- Если сообщений нет — переходит в ожидание новых сообщений.  

**Sender:**

- Открывает файл для передачи сообщений.  
- Отправляет сигнал готовности процессу Receiver.  
- В цикле по команде с консоли отправляет сообщения ограниченной длины или завершает работу.  
- Если файл заполнен — переходит в ожидание.  

## Особенности реализации

- Сообщения организованы в виде кольцевой очереди FIFO.  
- Обеспечивается синхронизация доступа к файлу для корректной работы процессов.  
- Используются механизмы межпроцессного ожидания и сигналов.  

## Инструкция по запуску

- Запустите процесс Receiver.  
- Запустите необходимое количество процессов Sender.  
- Используйте консоль для управления передачей сообщений.
