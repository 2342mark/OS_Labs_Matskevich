# Лабораторная работа №5: Обмен данными по именованным каналам

## Цель

Освоение клиент-серверного взаимодействия по именованным каналам и управление совместным доступом к файлу.

## Задача

Создать серверный процесс и несколько клиентских процессов, обеспечивающих совместную работу с бинарным файлом.

## Описание работы

| Процесс  | Описание                                                                                                  |
|----------|-----------------------------------------------------------------------------------------------------------|
| Сервер   | - Создаёт бинарный файл с записями сотрудников                                                           |
|          | - Выводит содержимое файла на консоль                                                                    |
|          | - Запускает клиентов                                                                                      |
|          | - Обслуживает запросы клиентов на чтение и модификацию записей                                            |
|          | - Блокирует доступ к записи при модификации                                                              |
|          | - Разрешает параллельное чтение записи несколькими клиентами                                              |
|          | - После завершения клиентов выводит итоговое состояние файла                                              |
| Клиенты  | - Выполняют циклы запросов: модификация, чтение, выход                                                   |
|          | - При модификации запрашивают ключ записи, получают запись, вводят новые данные и отправляют изменения   |
|          | - При чтении запрашивают ключ записи, получают и выводят запись                                           |

## Особенности реализации

- Используются именованные каналы для связи между сервером и клиентами.  
- Управление блокировками для обеспечения целостности данных при одновременной работе.  
- Клиенты могут одновременно читать запись, но запись блокируется на время модификации.  

## Инструкция по запуску

- Запустите сервер.  
- Запустите необходимое количество клиентов.  
- Управляйте запросами через консоль клиентов.
