# Лабораторная работа №2: Создание потоков

## Цель

Изучить создание и управление потоками, а также межпотоковое взаимодействие и синхронизацию.

## Задача

Создать консольное приложение, состоящее из трёх потоков:

| Поток    | Описание                                                             |
|----------|----------------------------------------------------------------------|
| main     | Главный поток, управляющий процессом                                 |
| min_max  | Находит минимальный и максимальный элементы массива                  |
| average  | Вычисляет среднее арифметическое элементов массива                   |

## Описание работы программы

**Главный поток (main) выполняет:**

1. Считывает с консоли размер массива и элементы массива.  
2. Создаёт потоки min_max и average.  
3. Ожидает завершения потоков min_max и average.  
4. Заменяет минимальный и максимальный элементы массива на среднее арифметическое.  
5. Выводит обновлённый массив на консоль.  
6. Завершает работу.  

**Поток min_max выполняет:**

- Поиск минимального и максимального элементов массива.  
- После каждого сравнения приостанавливается на 7 миллисекунд.  
- Выводит найденные значения на консоль.  

**Поток average выполняет:**

- Вычисляет среднее арифметическое элементов массива.  
- После каждой операции суммирования приостанавливается на 12 миллисекунд.  
- Выводит рассчитанное среднее значение на консоль.  

## Особенности реализации

- Использование API операционной системы для создания и управления потоками.  
- Задержки реализованы с помощью функции приостановки потока на заданное время.  
- Главный поток ожидает завершения дочерних потоков для корректной синхронизации.  

## Инструкция по запуску

- Запустите программу из консоли.  
- Введите размер массива.  
- Введите элементы массива.  
- Ознакомьтесь с выводом потоков и итоговым изменённым массивом.
